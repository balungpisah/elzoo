## Records and canonical bytes

`%Elzoo.DurableLog.Record{stream, sequence, kind, schema_version, payload,
nonce, digest}`; outbox item `%Elzoo.Outbox.Item{stream, sequence, position,
destination, idempotency_key, payload}`; checkpoint
`%Elzoo.Checkpoint{stream, sequence, fold_version, model, digest}`.

- `stream`: binary, 1..200 bytes, UTF-8. `sequence`: integer ≥ 1, assigned by
  the append (`expected + i`), never by the caller. `kind`: binary from the
  consumer's declared kind table; `schema_version`: positive integer from the
  consumer's declared version set. `payload`: opaque binary ≤ `max_record_bytes`
  (consumer encodes, e.g. Jason; Elzoo does not interpret it). `nonce`: 16
  random bytes from `:crypto.strong_rand_bytes/1`, fresh per append call,
  shared by every record/outbox item of that batch.
- `digest` = SHA-256 (`:crypto.hash/2`) over the canonical encoding
  `<<1::8, byte_size(stream)::32, stream::binary, sequence::64,
  byte_size(kind)::32, kind::binary, schema_version::32, byte_size(nonce)::32,
  nonce::binary, byte_size(payload)::32, payload::binary>>` (format version 1
  prefix; no `term_to_binary`). The digest detects corruption, not tampering.
- Outbox idempotency key is derived, never caller-chosen:
  `"<stream>/<sequence>/<position>"`, stable across restarts and redelivery.
- **Untrusted input.** Every row returned by a provider is re-validated
  (types, sizes, digest recomputation, kind/version membership). Strings from
  storage are never converted to atoms; kinds/destinations map through the
  consumer's fixed binary tables. No trust is upgraded from a provider reply,
  and no durability/ack field is guessed: absent or malformed fields are
  `indeterminate` (write) or damaged (read).

## Store boundary (`Elzoo.DurableLog.Store` behaviour)

All callbacks take `store :: {module, opts}` and never raise to the caller
(the shell maps raise/exit/throw/timeout itself; see write results).

    head(store, stream) :: {:ok, %{revision: non_neg_integer, low_water: non_neg_integer}} | {:error, :unavailable | :malformed}
    append(store, stream, expected_revision, [record], [outbox_item]) :: write_result
    read(store, stream, from_sequence, limit) :: {:ok, [row], head} | {:error, {:pruned, low_water} | :unavailable | :malformed}
    read_at(store, stream, sequence) :: {:ok, row | :absent, head} | {:error, :unavailable | :malformed}
    put_checkpoint(store, checkpoint) :: write_result
    latest_checkpoint(store, stream, fold_version) :: {:ok, checkpoint | :none} | {:error, ...}
    retain(store, stream, through_sequence) :: write_result
    pending(store, stream, limit) :: {:ok, [outbox_row]} | {:error, ...}
    ack(store, item_id, ack_nonce) :: write_result
    repair_torn_tail(store, stream, torn_sequence) :: write_result   # writer-only

### Write results (R10)

| Result | Meaning | Producer (named) |
| --- | --- | --- |
| `{:committed, revision}` | The provider acknowledged the commit; `revision` is the new head. The **only** commit point. | provider `COMMIT` returned ok and the reply validated |
| `{:conflict, %{expected: e, observed: h \| :unknown}}` | Confirmed stale expected revision (CAS matched 0 rows, or `(stream, sequence)` already present); transaction rolled back; nothing replaced | head CAS / unique violation reported by a statement **before** `COMMIT` |
| `{:rejected, reason}` | Confirmed preflight limit; **no provider call made** | `Elzoo.DurableLog.preflight/3`; reasons: `:empty_batch :batch_too_large :record_too_large :invalid_stream :invalid_revision :unknown_kind :unsupported_version :invalid_outbox_item :checkpoint_beyond_tail :retention_beyond_checkpoint` |
| `{:indeterminate, %{stream, expected, nonce, cause}}` | Storage may hold either state. `cause` ∈ `:exception :exit :timeout :malformed_reply :unavailable` | any raise/exit/throw, call timeout, `DBConnection.ConnectionError`, error during/after `COMMIT`, any reply outside this table |

A provider reporting "unavailable" is `indeterminate`, never `rejected` or
`conflict`. An exit reason or timeout never establishes non-execution.

Readback confirmation, `Elzoo.DurableLog.confirm(store, stream, expected,
nonce, digests)`, reads `read_at(expected + 1 .. expected + n)`:

| Observation | Result |
| --- | --- |
| every position holds exactly the written bytes (digest) **and** the nonce | `{:committed, expected + n}` |
| position `expected + 1` absent and head = `expected` | `:not_committed` (a new write needs a new nonce) |
| a record with a different nonce/digest at `expected + 1` | `:superseded` (ours did not commit; CAS exclusivity) |
| read error / malformed / partial match | `{:unknown, cause}` (stay down; never guess) |

### Writer (`Elzoo.DurableLog.Writer`)

One GenServer per stream, started by the consumer's supervisor (no
`Elzoo.Application`). `start_link(store:, stream:, fold:, limits:, checkpoint:
optional)`. On init it is the **owning writer**: reads head, optional latest
checkpoint, tail; if the tail is torn it calls `repair_torn_tail` (CAS on the
current head) and re-reads; then folds. `append(writer, [{kind, version,
payload}], [{destination, payload}], timeout)`:

- `committed` → model refolded with the new records, reply `{:committed, rev}`;
- `conflict` → re-reads the tail, refolds, replies `{:conflict, observed}`;
- `rejected` → state unchanged, reply;
- `indeterminate` → replies `{:indeterminate, info}` and **stops**
  `{:shutdown, {:indeterminate_write, info}}`; the next writer's init runs
  `confirm/5` for the recorded nonce only when the caller supplies it (the
  writer never holds durable memory of it); init always rebuilds from the
  authoritative store, so a committed-but-unacknowledged write is folded and an
  uncommitted one is absent. A caller `GenServer.call` timeout is caller-side
  unknown.

The Writer is single-writer by convention; correctness against a second writer
relies on the store CAS (K2), not on process uniqueness. No lease (ELZ-028).

### Read / replay results (R6, R7, R12)

`Elzoo.DurableLog.replay(rows, head, fold)` with `fold = %{initial: model,
reduce: (model, kind, version, payload -> model), kinds: %{binary =>
:state_bearing | :non_state_bearing}, versions: [pos_integer]}` returns
`%{model, cursor: {applied, damaged, diagnostics}, tail: :intact | :torn}`.

- **Order backstop:** rows are folded by `sequence`, then provider append
  order (the double keeps insertion order; Postgres orders by the unique
  `(stream, sequence)` key, so equal sequences cannot be returned).
- `classify` (Cure) → `ReplayNext` (= applied + 1), `ReplayGap` (> applied + 1:
  record applied, `damaged = true`, diagnostic), `ReplayDuplicate`/
  `ReplayOutOfOrder` (≤ applied: model unchanged; out-of-order (< applied) is
  a diagnostic, an exact repeat of `applied` is a duplicate and ignored). The
  pinned compiler classifies only from the cursor; Elixir distinguishes exact
  repeat vs earlier sequence before calling `classify`, test-grounded.
- **Totality over kinds:** every stored kind must be in `kinds`; a
  `:non_state_bearing` kind advances the cursor but never calls `reduce`. A kind
  not in the table, or a version outside `versions`, is treated as interior
  corruption (below), never silently skipped.
- **Interior corruption** (digest mismatch, malformed row, unknown
  kind/version at sequence < head): fold stops; result is the model of the
  longest valid prefix, `damaged = true`, diagnostic `{:corrupt, seq, reason}`.
  Later rows are not applied.
- **Torn final record** (only the row at `sequence = head` invalid): tolerated,
  model of the prefix, `tail: :torn`, `damaged` unchanged. Only the owning
  Writer at init may call `repair_torn_tail`; `replay/3`, `read/4`,
  `Elzoo.Checkpoint` and `Elzoo.Outbox` never write (audited by a test that
  replays through a store double that fails any mutating call).
- **Truncation:** a head revision greater than the last readable row is a
  forward gap at the tail → `damaged = true`, `{:truncated, head, last}`.
  Reading below `low_water` returns `{:error, {:pruned, low_water}}`.
- **Unavailable:** `{:error, :unavailable}`; the Writer does not start (init
  returns `{:stop, {:storage, :unavailable}}`), no partial model is served.

Postgres row atomicity means a torn row is unobservable through
`integration/sql` (upstream transaction contract); torn-tail and interior
corruption are exercised through `Memory` fault injection and a direct
out-of-band `UPDATE` of a stored digest in the Postgres test database.

### Checkpoint (`state/checkpoint`)

`Elzoo.Checkpoint.take(writer_or_store, stream, fold_version, encode)` writes
`(stream, sequence = applied, fold_version, model_bytes, digest)` via
`put_checkpoint`, which the store accepts only when `sequence ≤ head` in the
same transaction (else `{:rejected, :checkpoint_beyond_tail}` from preflight or
`conflict` from the store). `recover(store, stream, fold, fold_version,
decode)` = latest checkpoint with matching `fold_version` and valid digest,
then tail replay from `sequence + 1`. A checkpoint with a different
fold_version, bad digest or undecodable model is ignored (refold from an
earlier checkpoint or from the start), never trusted. **Equivalence claim:**
`recover` and a full `replay` from sequence 1 yield the same model and cursor
for every listed prefix (test-grounded, D7/D8). **Tail retention:**
`retain(stream, through)` deletes records `≤ through` and raises `low_water`
only if a committed checkpoint with `sequence ≥ through` exists, in one
transaction; otherwise `{:rejected, :retention_beyond_checkpoint}`. Outbox rows
are never deleted by retention while pending.

### Outbox (`state/outbox`)

- **Commit:** outbox items are inserted by the same `append` transaction as
  the head CAS and records (R11 "head advance + immutable version record +
  committed change event are one commit"). The in-memory batch passed to
  `append` is transient; only the committed outbox row is a durable source.
- **Offer:** `Elzoo.Outbox.pending(store, stream, limit)` returns committed
  rows with `state = pending` ordered by `(sequence, position)`. Rows are
  validated like records.
- **Ack (commit point):** `Elzoo.Outbox.ack(store, item_id, ack_nonce)` is a
  CAS `pending → acked`; `{:committed, _}` is the only acknowledgement; a
  second ack is `conflict`; error is `indeterminate` (readback by
  `ack_nonce`). An acked item is never offered again.
- **Dispatch failure** is a separate post-commit outcome owned by the caller
  (ELZ-010/011): the item stays pending. No attempt count, deadline or
  dispatcher lives here; no external effect is executed or replayed by this
  task. Delivery to a dispatcher is **at-least-once** (crash between dispatch
  and ack re-offers), deduplicated downstream only by the derived key.
- Replay/refold never creates, re-inserts or re-offers acked outbox items
  ("a committed item is not emitted twice" in the acceptance sense).

### Tiers (R8)

Durable tier: head, records, checkpoints and outbox rows committed by the
provider. Ephemeral tier: the Writer's folded model and cursor, the in-memory
append batch, any caller-side notification. Every ephemeral value is
reconstructable by `recover`; no durable write reads an ephemeral value except
the expected revision, which the store re-checks by CAS.

## Postgres mapping (`integration/sql`)

`Elzoo.DurableLog.Postgres.Migration.up/0` (consumer runs it in its own Ecto
migration; tests use `Ecto.Migrator`):

| Table | Columns / constraints |
| --- | --- |

| `elzoo_log_records` | `stream`, `sequence bigint`, `kind text`, `schema_version int`, `payload bytea`, `nonce bytea`, `digest bytea`; **PK `(stream, sequence)`** |
| `elzoo_outbox` | `stream`, `sequence`, `position int`, `destination text`, `payload bytea`, `nonce bytea`, `digest bytea`, `state text CHECK IN ('pending','acked')`, `ack_nonce bytea NULL`; PK `(stream, sequence, position)`; FK to records |
| `elzoo_checkpoints` | `stream`, `sequence`, `fold_version int`, `model bytea`, `digest bytea`; PK `(stream, sequence, fold_version)` |

`append` = one `Repo.transaction`: `INSERT heads … ON CONFLICT DO NOTHING`
(expected 0) or `UPDATE heads SET revision = e + n WHERE stream = $1 AND
revision = e` → 0 rows ⇒ `Repo.rollback(:conflict)`; `INSERT` records; `INSERT`
outbox rows; `COMMIT`. Default READ COMMITTED: a concurrent CAS blocks on the
row lock and re-evaluates the `WHERE` against the committed row (upstream
PostgreSQL contract), yielding 0 rows. The adapter takes the consumer's Repo
module (`{Elzoo.DurableLog.Postgres, repo: MyRepo, prefix: optional}`); no
Repo, config or Application is shipped. Fault-injection hooks
(`:before_commit`, `:after_commit_reply`) are test options only.

Test harness: `mix check` requires `ELZOO_TEST_DATABASE_URL` (a disposable
local database) and **fails closed** with an explicit message when it is
absent or unreachable; Postgres scenarios are never silently skipped. CI change
(task-scoped, for independent review): the existing "Prepare Ubuntu job
container" step additionally installs `postgresql` from the pinned
`ubuntu:24.04@sha256:fe8156…` container's apt repository, a new step starts
the cluster with `pg_ctlcluster`, creates a throwaway role/database and exports
the URL. No new runner, label, hosted fallback, Docker image pull or
`runs-on` change; `check-ci-runners.py` unchanged. The server version is
reported in the log (observed, not pinned — like other apt packages) and the
tests record `server_version`, `fsync` and `synchronous_commit` as monitored
observations of the test cluster.

## Provider evaluation (R2, R13)

Named conformance checks, `Elzoo.DurableLog.Conformance.checks/0`, are plain
functions over a `store` that return `:ok | {:error, detail}` so the same list
runs against every candidate:

| ID | Check |
| --- | --- |
| K1 `append_readback` | committed append reads back identical bytes/nonce at the reported revision |
| K2 `cas_exclusivity` | 16 concurrent appends with the same expected revision → exactly one `committed`, the rest `conflict`; head = expected + n |
| K3 `stale_conflict_replaces_nothing` | stale expected → `conflict`; records/outbox unchanged |
| K4 `duplicate_insert_refused` | inserting an existing `(stream, sequence)` (bypassing head) is refused by the store, not by writer memory |
| K5 `atomic_head_record_outbox` | failure injected after record/outbox inserts, before commit → none of head/record/outbox visible |
| K6 `unavailable_readback` | provider unavailable / reply lost after commit → `indeterminate`; `confirm` returns `committed` iff exact bytes+nonce at expected+1, `not_committed` otherwise |
| K7 `checkpoint_bounded_by_tail` | checkpoint beyond head refused |
| K8 `ack_cas` | ack `pending → acked` once; second ack `conflict`; acked never re-offered |
| K9 `restart_replay` | fresh connection/process: same fold, same pending set |
| K10 `preflight_writes_nothing` | every `rejected` reason leaves the store unchanged and makes no provider call |
| K11 `retention_bounded_by_checkpoint` | retain beyond checkpoint refused; within → pruned read returns `{:pruned, low_water}` |

| Candidate | How exercised | Planned role |
| --- | --- | --- |
| `Elzoo.DurableLog.Memory` (test double; GenServer over a map) | K1–K11 + fault injection (torn tail, interior corruption, unavailable, reply loss) | test double only; volatile; never a durability claim |
| PostgreSQL via Ecto SQL 3.14.0 / Postgrex 0.22.4 | K1–K11 against a disposable local database, including a real `pg_terminate_backend` mid-transaction and a stopped/unreachable server | **proposed selection** |
| AshPostgres 2.15.2 (Ash 3.37.3) in `spikes/ash_foundation` | same K1–K5, K8 through Ash resources over the same tables (create actions, an `update` with `optimistic_lock(:revision)`-style CAS, `Ash.transact`) against the same test database | comparison; record pass/fail per check |
| OTP `disk_log` (OTP 29.1.2) | K2/K4/K5 probe: two writers appending to one log | negative comparison: expected to fail store-level uniqueness/CAS/atomic multi-record commit, demonstrating why it is not the boundary |
| Reactor 1.0.7 (transitive in the spike) | probe: kill the process during a step; a new run has no persisted progress | reject for this boundary (in-process saga/compensation, not durable state); left to ELZ-010 as an execution candidate |
| AshOban 0.10.3 / Oban 2.24.2 | not exercised here | deferred to ELZ-010 (`integration/jobs`, `state/scheduler`); the Postgres/Ecto selection keeps a same-transaction outbox → job insert possible, **unverified** until ELZ-010 |
| SQLite (ecto_sqlite3 0.26.0) | not exercised | recorded as an unevaluated alternative, not rejected on merit |

Selection rule (fixed before running): choose the provider that passes every
K-check at the boundary with the fewest consumer dependencies. If Ecto/Postgrex
and AshPostgres both pass, select Ecto/Postgrex for the copied adapter (the
Store is infrastructure below application resources; ADR-0005 forbids a
wrapper that only renames Ash APIs and does not require Ash in every bundle),
and record AshPostgres as a compatible layer over the same tables. If
Ecto/Postgrex fails any K-check, stop and return the finding for review rather
than weakening the check.

## Decisions recorded

- **Hash chain (for `state/audit-log`):** not adopted here. Per-record
  SHA-256 detects corruption, not tampering by a party that can write the
  store. An append-time chain over canonical records is needed only if
  `state/audit-log` requires tamper evidence against a store-privileged writer;
  that task decides. No default chain is implemented.
- **Exactly-once:** not claimed. Records commit at most once per nonce under
  CAS; outbox delivery to a dispatcher is at-least-once.
- **Schema evolution:** records carry `schema_version`; only declared versions
  replay; upcasting/golden corpora belong to ELZ-010.

# SPDX-License-Identifier: Apache-2.0
mod Elzoo.Replay
  use Std.Option

  type ReplayOrder = ReplayNext | ReplayDuplicate | ReplayOutOfOrder | ReplayGap
  type RecordUse = StateBearing | NonStateBearing

  rec ReplayDiagnostic
    sequence: Int
    order: ReplayOrder

  rec ReplayCursor
    applied: Int
    damaged: Bool
    diagnostics: List(ReplayDiagnostic)

  rec ReplayCount
    cursor: ReplayCursor
    total: Int

  fn initial() -> ReplayCursor = ReplayCursor{applied: 0, damaged: False(), diagnostics: []}

  fn classify(cursor: ReplayCursor, sequence: Int) -> ReplayOrder =
    pickup
      sequence == cursor.applied + 1 -> ReplayNext()
      sequence > cursor.applied + 1 -> ReplayGap()
      else -> ReplayDuplicate()

  @total true
  @reducible
  fn admits(order: ReplayOrder, role: RecordUse) -> Bool =
    match order
      ReplayNext() -> bearing(role)
      ReplayGap() -> bearing(role)
      ReplayDuplicate() -> False()
      ReplayOutOfOrder() -> False()

  @total true
  @reducible
  fn bearing(role: RecordUse) -> Bool =
    match role
      StateBearing() -> True()
      NonStateBearing() -> False()

  @total true
  @reducible
  fn track(cursor: ReplayCursor, sequence: Int, order: ReplayOrder) -> ReplayCursor =
    match order
      ReplayNext() -> ReplayCursor{applied: sequence, damaged: cursor.damaged, diagnostics: cursor.diagnostics}
      ReplayGap() -> ReplayCursor{applied: sequence, damaged: True(), diagnostics: [ReplayDiagnostic{sequence: sequence, order: order} | cursor.diagnostics]}
      ReplayDuplicate() -> cursor
      ReplayOutOfOrder() -> ReplayCursor{applied: cursor.applied, damaged: cursor.damaged, diagnostics: [ReplayDiagnostic{sequence: sequence, order: order} | cursor.diagnostics]}

  @total true
  @reducible
  fn count_step(state: ReplayCount, sequence: Int, value: Int, order: ReplayOrder, role: RecordUse) -> ReplayCount =
    ReplayCount{cursor: track(state.cursor, sequence, order), total: add_if(admits(order, role), state.total, value)}

  @total true
  @reducible
  fn add_if(admitted: Bool, total: Int, value: Int) -> Int =
    match admitted
      True() -> total + value
      False() -> total

  @total true
  @reducible
  fn total_of(state: ReplayCount) -> Int = state.total

  @total true
  @reducible
  fn cursor_of(state: ReplayCount) -> ReplayCursor = state.cursor

  @total true
  @reducible
  fn damaged_of(cursor: ReplayCursor) -> Bool = cursor.damaged

  @total true
  @reducible
  fn applied_of(cursor: ReplayCursor) -> Int = cursor.applied

  fn duplicate_keeps_total(state: ReplayCount, sequence: Int, value: Int, role: RecordUse) -> Equivalent(Int, total_of(count_step(state, sequence, value, ReplayDuplicate(), role)), total_of(state)) =
    reflexive(total_of(state))

  fn duplicate_keeps_cursor(state: ReplayCount, sequence: Int, value: Int, role: RecordUse) -> Equivalent(ReplayCursor, cursor_of(count_step(state, sequence, value, ReplayDuplicate(), role)), cursor_of(state)) =
    reflexive(cursor_of(state))

  fn out_of_order_keeps_total(state: ReplayCount, sequence: Int, value: Int, role: RecordUse) -> Equivalent(Int, total_of(count_step(state, sequence, value, ReplayOutOfOrder(), role)), total_of(state)) =
    reflexive(total_of(state))

  fn out_of_order_keeps_applied(state: ReplayCount, sequence: Int, value: Int, role: RecordUse) -> Equivalent(Int, applied_of(cursor_of(count_step(state, sequence, value, ReplayOutOfOrder(), role))), applied_of(cursor_of(state))) =
    reflexive(applied_of(cursor_of(state)))

  fn gap_marks_damaged(state: ReplayCount, sequence: Int, value: Int, role: RecordUse) -> Equivalent(Bool, damaged_of(cursor_of(count_step(state, sequence, value, ReplayGap(), role))), True()) =
    reflexive(True())

  fn non_state_bearing_keeps_total(state: ReplayCount, sequence: Int, value: Int) -> Equivalent(Int, total_of(count_step(state, sequence, value, ReplayNext(), NonStateBearing())), total_of(state)) =
    reflexive(total_of(state))
end

## Contract and architecture

All eight prerequisites were read closed: #55/#6/#11/#37/#153/#165/#171/#185.
The coordinator reported ELZ-099's PR #188 merge/main acceptance; this base
contains it. Historical manifest status does not override accepted live state.
No dependency/toolchain/configuration pins or ready Contracts change.

The owner serializes actual caller authority, exact request validation,
identity/conflict indexing and inherited Cure Backpressure admission. Sessions
own linked temporary Task.Supervisors, live bootstrap parents of actual
EffectIntent owners, their Adapter tasks, distinct HTTP workers and isolated
sink workers. Custody is registered before launch. Source stop freezes provider
usage and enters finishing; only the matching HTTP halted result and DOWN can
offer finish. Only its timely matching ack commits local delivery. Supervisor
and worker/intent monitors precede retained summaries/capacity removal.

The charged bridge uses the actual intended/dispatched append/checkpoint
barriers and existing host activation. It never rearms. Adapter schema,
binding/arguments digest, local generation and attempt are checked before the
Need/HTTP handoff. Completion is a sealed digest-only existing Envelope; lost
settlement is separately unconfirmed. Normal Need failure is the only attested
no-send tag. Store/timeout/cancellation/worker death never creates a no-send
certificate or resend authority.

Transport uses a fresh low-level Req request with exactly its built-in steps,
function-into, retries/redirects/decode/decompression off and fixed HTTP1 pool
construction. The current Finch options interface receives the result of
Req.Finch.pool_options applied to fixed connect settings; no pool option varies
with deadline/identity. Raw byte accounting precedes header/status/body
classification; non-200 status takes precedence over discarded body size.
A separate bounded raw framer resolves real CR/LF/BOM boundaries before calling
the unmodified maintained parser with one block. JSON ordered objects reject
all duplicate decoded keys before map projection. No output history/backlog.

Exact nested usage replacement/null semantics are independent of sink results.
Interim start-only output is unknown in final usage. Valid source stop freezes
provider-reported usage even if finish delivery/cleanup/settlement later fails.
The maximal terminal schema is preflighted using recursively struct-stripped,
uncompressed deterministic ETF, without dropping observations to fit.

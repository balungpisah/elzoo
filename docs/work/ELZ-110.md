## Implementation and source grounding

One 74-line Python helper, no general source parser or retry framework. It keeps primary
update/install behavior, then permits one official HTTPS archive fallback with
a strict refresh before the last installation attempt. Unsupported configuration
refuses before writing. Only known URI tokens in the canonical Ubuntu deb822
file change; trust attributes, suites/components, unrelated sources and the
mirror list remain unchanged. Explicit Enabled fields and legacy source layouts
are unsupported, not silently inferred. See the CI documentation for the exact
supported forms and checkout/S3/Gleam working-directory boundary.

Actual maintained runner-image source inspected at commit
`e06ccbf37708c99aa5d2db14c9e9c4a2664ed761`:
[configure-apt-sources.sh](https://github.com/actions/runner-images/blob/e06ccbf37708c99aa5d2db14c9e9c4a2664ed761/images/ubuntu/scripts/build/configure-apt-sources.sh)
(Git blob `b3f5b2b180df8eb39fcbba034f616e03a69e775c`). It creates the 144-byte
mirror list with Azure/archive/security URLs and tab-separated priorities 1/2/3,
then substitutes the mirror+file URI into ubuntu.sources on 24.04. The fixture
uses those actual lines, not guessed package descriptions. This source inspection
does not establish the image revision of a particular hosted job.

[Ubuntu Noble apt-get manual](https://manpages.ubuntu.com/manpages/noble/man8/apt-get.8.html)
documents strict update errors (`--error-on=any`) and authentication defaults.
The helper uses `APT::Update::Error-Mode=any` and adds no trusted/insecure override.
APT's signed-repository and package-validation behavior remains upstream's
contract, not a new local supply-chain proof.

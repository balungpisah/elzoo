prompts. This change is documentation and inventory, not runtime implementation.

## Limits

No upstream application or its tests were executed. Reading source and tests
is evidence of the design and scenarios represented, not proof that they pass
or that the product is secure/durable. Package metadata does not establish API
fitness. No claim of universal coverage, production financial/identity behavior,
or outperforming the reference products. No autonomous worker prompt was issued.

## Lessons

- Similar nouns hide distinct invariants: Work Item versus Run/Attempt, quota
  versus budget/rate limit, and authorization versus exact-action approval.
- Common invocation syntax does not establish common delivery guarantees.
- A timeout after an external effect is an unknown outcome; missing local
  observation is not evidence that retry is safe.
- Catalogue breadth can be recorded without pretending every row is ready or
  converting every candidate into an implementation assignment.

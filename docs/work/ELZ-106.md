## Implementation and ownership

One direct-call module, no process or transport abstraction. The only runtime
calls are fixed public Prometheus counters/registry/formatter, telemetry manual
registration and application-environment inspection. Frozen five-pair projection
and six event names produce at most 15 event series and 10 duration series.
Read only event/pair and applicable integer duration. Ignored metadata is never
traversed, logged or supplied to the provider. Count and duration updates are
not transactional; invalid duration retains the valid event count.

Initialization checks empty entry and refuses preexisting definitions without
adoption. On a declaration failure after empty-entry validation, public metric
deregistration plus counter-collector deregistration cleans the partial state.
Provider loss during cleanup returns unavailable without claiming rollback.
Attach/scrape use exactly the counter collector and public three-label value
probes; missing/arity failures differ from a valid undefined series. These
checks do not prove definition provenance: successful initialization and the
exclusive/immutable host Needs establish that, as admitted.

Manual singleton attachment is independent of the attacher and provider-owned
metrics. Duplicate attach does not reset totals. Detach does not drain selected
callbacks and delayed administration has no owner token. Restart loses metrics,
not necessarily registration; explicit initialization restores definitions.
All catchable projection/provider failures stay inside the callback rather than
telemetry's raw reason/stacktrace/config failure path. No hard caller latency,
global memory, numeric magnitude, durable delivery or accounting guarantee.

Excluded production boundaries are untouched: durable-job, Store/Writer, Relay,
outbox, EffectIntent and runtime/telemetry. Historical TimescaleDB hosting remains
unchanged; this opt-in direct Prometheus slice does not adopt an OTel stack.

The loopback HTTP fixture holds a scraper while updates finish, then checks the
actual text body using a local socket client; updates also finish with no listener.
There is no timing threshold or sleep-established race assertion.

The actual copier selects the Piece plus runtime/telemetry by temporary in-memory
registration, following existing Piece-local copy tests. The independent consumer

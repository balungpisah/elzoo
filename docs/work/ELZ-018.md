## Lessons

- A copied bundle loses its original directory boundary: auditing a glob of
  consumer cure/ also includes other bundles. Each owning test must audit its
  own explicit source set; the Adapter's declared axiom is not a pure-module bug.
- Build-time compiler startup and runtime dependency are different claims. Test
  runtime absence in a fresh VM, not after the compiler ran in the test VM.
- Correcting evidence/applicability descriptions without changing behavior is
  distinct from changing a ready behavioral Contract.

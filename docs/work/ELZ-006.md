## Split rationale (capability-model step 4)

- Admission capacity (backpressure) is chosen independently of retry policy
  (a receiver can bound in-flight work without retries) → separate Piece.
- The dead-letter record is also needed without retries (malformed/permanent
  rejection, architecture "explicit error/dead-letter outcome") → separate
  pure data Piece.
- Classification, retry limit, backoff, deadline expiry and the OTP shell that
  executes attempts/timeouts share one invariant ("an operation settles exactly
  once, and a possibly-dispatched outcome is never blindly re-dispatched") →
  one Piece `delivery/retry-timeout` with a pure Cure policy and its Elixir/OTP
  runner. The runner composes the other two; it is not an Assembly of routing
  (ELZ-008).

## Piece: `delivery/backpressure`

- Path `pieces/delivery/backpressure/`. Dependencies: none (providers `cure`, `elixir`).
- Cure `Elzoo.Backpressure` (`cure/elzoo/backpressure.cure`); Elixir boundary
  `Elzoo.Backpressure` (`lib/elzoo/backpressure.ex`). Pure; no process/clock/I/O.

New Cure declarations:

| Declaration | Erased form (to be measured by probe before implementation) |
| --- | --- |
| `rec CapacityState` (capacity: Int, in_flight: Int) | `{:CapacityState, capacity, in_flight}` |
| `type AdmissionDecision = Admitted \| Saturated \| CapacityInvalid` | atoms |
| `type ReleaseDecision = Released \| ReleaseUnderflow` | atoms |

Pure API:

    fn initial(capacity: Int) -> CapacityState                  # in_flight 0
    fn classify_admit(state: CapacityState) -> AdmissionDecision
    @total true
    fn admit_step(state: CapacityState, decision: AdmissionDecision) -> CapacityState
    fn admit(state) = admit_step(state, classify_admit(state))  # returns {decision, state} via record pair
    fn classify_release(state: CapacityState) -> ReleaseDecision
    @total true
    fn release_step(state: CapacityState, decision: ReleaseDecision) -> CapacityState

| # | Condition | Decision | Next state |
| --- | --- | --- | --- |
| 1 | `capacity < 1` or `in_flight < 0` or `in_flight > capacity` | CapacityInvalid | unchanged |
| 2 | `in_flight == capacity` | Saturated | **unchanged** (nothing admitted, nothing evicted, nothing queued) |
| 3 | otherwise | Admitted | `in_flight + 1` |
| R1 | `in_flight < 1` | ReleaseUnderflow | unchanged |
| R2 | otherwise | Released | `in_flight - 1` |

Capacity is **in-flight operations, queue length 0**: there is no waiting
queue; work beyond the bound is refused, not buffered. Elixir boundary:
`new(capacity) :: {:ok, state} | {:error, :invalid_capacity}` (positive integer);
`admit(state) :: {:ok, state, :admitted | :saturated} | {:error, :invalid_state}`;
`release(state) :: {:ok, state} | {:error, :invalid_state | :release_underflow}`.
Config: construction-time `capacity`, no hot reconfiguration.

- Path `pieces/delivery/dead-letter/`. Dependencies: `core/envelope`.
- Cure `Elzoo.DeadLetter`; Elixir `Elzoo.DeadLetter`. Pure data + validation.

Neutral map (exact string keys, like core/envelope): `version` (1),

### Classification (Cure `classify({a: Type}, result: DeliveryResult(a)) -> ResultClass`)

Input is a result already accepted by `Elzoo.Envelope.validate_result/1` and
`Elzoo.RequestReply.correlate/2` for the current attempt.

| outcome / dispatch | error_class | ResultClass |
| --- | --- | --- |
| completed / dispatched | — | ClassCompleted |
| rejected or timed_out / not_dispatched | retryable, unavailable, unclassified | ClassRetryable (no dispatch reported, so a retry adds no second Effect per the boundary's report) |
| any / any | permanent | ClassPermanent |
| failed / dispatched; timed_out / dispatched or unknown; unknown / dispatched or unknown | retryable, unavailable, unclassified | ClassDispatched (possible external Effect, outcome unknown or partial) |

### Decision (`decide(policy, attempt, class) -> RetryDecision`, `attempt` = attempts made ≥ 1)

| class | mode | attempt < max_attempts | Decision |
| --- | --- | --- | --- |
| ClassCompleted | any | any | DecideSettle |
| ClassPermanent | any | any | DecidePermanent |
| ClassRetryable | any | yes | DecideRetry |
| ClassRetryable | any | no | DecideExhausted |
| ClassDispatched | RedispatchForbidden | any | DecideUnresolved (**never retried**) |
| ClassDispatched | RedispatchIdempotent | yes | DecideRetry |
| ClassDispatched | RedispatchIdempotent | no | DecideExhausted |

`decide` must route through the production helper
`retry_permitted(mode: RedispatchMode, class: ResultClass) -> Bool`
(matching `class` first), so the selected laws below constrain the code that
runs. `backoff(policy, attempt) = min(base_backoff_ms * 2^(attempt-1), max_backoff_ms)`,
deterministic, no jitter. `RedispatchIdempotent` is a **caller assertion**
that the receiver/provider deduplicates by the unchanged `idempotency_key`
(or is naturally idempotent); it is recorded as an assumption, never verified.
Even `retryable` never authorizes a blind retry under the default mode,
matching the core/envelope README and docs/capability-model.md.

Policy validation: `max_attempts ≥ 1`, `0 ≤ base_backoff_ms ≤ max_backoff_ms`,
integers; mode atom `:redispatch_forbidden | :redispatch_idempotent`.
Elixir: `RetryTimeout.policy(opts) :: {:ok, policy} | {:error, :invalid_max_attempts | :invalid_backoff | :invalid_mode}`;
`classify(result_map)`, `decide(policy, attempt, class)`, `backoff(policy, attempt)`.

### Runner `Elzoo.RetryTimeout.Runner` (timeout execution, OTP)

    start_link(opts)   # :capacity, :policy, :attempt_timeout_ms (pos int),
                       # :attempt (fn envelope_map -> DeliveryResult map),
                       # :dead_letter (fn record_map -> :ok | {:error, atom}),
                       # :now_ms (0-arity, default System.os_time(:millisecond)),
                       # :task_supervisor (name/pid of a caller-supervised Task.Supervisor)
    submit(runner, envelope_map)
      :: {:ok, ref}
       | {:error, {:saturated, delivery_result_map}}         # rejected/not_dispatched/unavailable
       | {:error, {:expired, delivery_result_map}}           # timed_out/not_dispatched/permanent
       | {:error, {:envelope, reason}} | {:error, :attempt_id_present} | {:error, :operation_in_flight}
    snapshot(runner) :: %{capacity, in_flight, open, settled, dead_lettered, late_or_mismatched}

Settlement is sent once per accepted `ref` to the submitting pid as
`{Elzoo.RetryTimeout, ref, settlement}`:

    {:completed, delivery_result_map}     # validated, correlated, completed
    {:dead_lettered, dead_letter_map}     # sink returned :ok
    {:unsettled, dead_letter_map}         # sink returned an error/raised: NOT acknowledged

Lifecycle per operation (identity = effective correlation: `correlation_id`
or else `message_id`; one open operation per identity):

1. **Admission.** Decode the Envelope (core/envelope). Reject a request that
   already carries `attempt_id` (the runner owns attempts). If
   `deadline_unix_ms` is present and `deadline - now_ms() ≤ 0` → `:expired`
   (not admitted, nothing dispatched). Backpressure `admit`; `:saturated`
   returns the saturation result and **state is unchanged**. Otherwise admit,
   arm a deadline timer `Process.send_after(self(), {:deadline, token}, remaining)`
   (wall clock read only here, in the shell, once; Cure never reads a clock),
   and start attempt 1.
2. **Attempt n.** Envelope gets `attempt_id = "<message_id>/attempt/<n>"`;
   correlation/idempotency_key/deadline unchanged. Run `attempt` in a
   `Task.Supervisor.async_nolink` task; arm `{:attempt_timeout, token}`
   after `attempt_timeout_ms`.
3. **Observation.** Task reply → `validate_result` + `correlate` for this
   attempt; a failure to validate/correlate, a task crash, or the attempt
   timeout (task then shut down with `Task.Supervisor.terminate_child`)
   becomes the synthesized result `unknown/unknown/unclassified` or
   `timed_out/unknown/unclassified` respectively: the runner cannot know
   whether the attempt dispatched, so it **never** reports `not_dispatched`
   for these. Then `classify` → `decide`.
4. **Retry.** DecideRetry arms `{:retry_due, token}` after `backoff`; the slot
   stays admitted during backoff.
5. **Deadline.** `{:deadline, token}` for an open operation: an in-flight task
   is shut down; dead-letter reason `deadline_expired` with the last observed
   (or synthesized `timed_out/unknown`) result; a pending retry is cancelled.
   Deadline wins over a later retry/attempt message (stale tokens ignored).
6. **Settle.** DecideSettle → `:completed`. DecidePermanent / DecideExhausted /
   DecideUnresolved / deadline → dead-letter record (`permanent`,
   `retries_exhausted`, `dispatched_unresolved`, `deadline_expired`), then call
   the sink; `:ok` → `:dead_lettered`, else `:unsettled`. Every path cancels
   its timers and releases exactly one backpressure slot.

Acknowledgement relative to state/effect completion: `:completed` means only
that a validated, correlated `completed` result was observed for the current
attempt; it is the attempt function's report, not proof of a durable Effect.
`:dead_lettered` means the caller's sink returned `:ok`; its durability is the
sink's Contract. No result is ever reported `:completed` after a crash, timeout,
invalid result or sink failure. If the runner itself exits, no settlement is
sent; submitters must monitor the runner and treat a `DOWN` before settlement as
an **unknown outcome** (tested). Restart starts with empty volatile state and
full capacity; previously open operations are not resumed or replayed.

Late results: a reply from a task the runner has already timed out/shut down,
or any result failing `correlate` for the current attempt, never changes the
decision; it is counted in `late_or_mismatched` and otherwise discarded with
no payload retained. This is safe for state but the observation is lost; under
the default mode a dispatched/unknown attempt is never followed by another
dispatch, so a late success cannot collide with a retry. Under
`RedispatchIdempotent` the caller's dedup assumption covers it.

The runner's own mailbox is OTP-unbounded; `submit` is a `GenServer.call`
with the default 5000 ms caller timeout, and a caller-side timeout is itself
an unknown admission outcome (documented; the caller may receive a settlement
later).

### Shedding

The ready subset offers **no shedding** (newest-wins, drop-oldest or random
drop). At saturation work is refused with a declared result returned to the
submitter; admitted work is never evicted. Hence the amended acceptance item's
precondition ("any shed/drop policy") is not met and no reconstructability test
is owed; a future shedding policy needs its own Piece ID naming the durable
state that makes dropped items reconstructable plus that test.

## Limits (local policy vs network-wide guarantees)

Local, single-node, volatile policy. No durable queue, ack/redelivery
protocol, distributed credit, load balancing, cross-node deadline, exactly-once
Effect or at-least-once delivery guarantee. Capacity bounds in-flight
operations of one runner, not mailbox bytes or a cluster. A retry is a new
attempt of the same operation; it is not proof the earlier attempt had no
Effect except where the boundary reported `not_dispatched` (itself an Adapter
report). Timer firing is not exact. No circuit breaker/bulkhead (separate
planned ID). Not the complete historical Zoo receiver.

Probe `backpressure.cure`:

    mod Elzoo.Backpressure
      rec CapacityState
        capacity: Int
        in_flight: Int

      type AdmissionDecision = Admitted | Saturated | CapacityInvalid
      type ReleaseDecision = Released | ReleaseUnderflow

      fn initial(capacity: Int) -> CapacityState = CapacityState{capacity: capacity, in_flight: 0}

      fn classify_admit(state: CapacityState) -> AdmissionDecision =
        pickup
          state.capacity < 1 -> CapacityInvalid()
          state.in_flight < 0 -> CapacityInvalid()
          state.in_flight > state.capacity -> CapacityInvalid()
          state.in_flight == state.capacity -> Saturated()
          else -> Admitted()

      @total true
      @reducible
      fn admit_step(state: CapacityState, decision: AdmissionDecision) -> CapacityState =
        match decision
          Admitted() -> CapacityState{capacity: state.capacity, in_flight: state.in_flight + 1}
          Saturated() -> state
          CapacityInvalid() -> state

      fn classify_release(state: CapacityState) -> ReleaseDecision =
        pickup
          state.in_flight < 1 -> ReleaseUnderflow()
          else -> Released()

      @total true
      @reducible
      fn release_step(state: CapacityState, decision: ReleaseDecision) -> CapacityState =
        match decision
          Released() -> CapacityState{capacity: state.capacity, in_flight: state.in_flight - 1}
          ReleaseUnderflow() -> state

      fn saturated_keeps_state(state: CapacityState) -> Equivalent(CapacityState, admit_step(state, Saturated()), state) =
        reflexive(state)

      fn invalid_keeps_state(state: CapacityState) -> Equivalent(CapacityState, admit_step(state, CapacityInvalid()), state) =
        reflexive(state)

      fn underflow_keeps_state(state: CapacityState) -> Equivalent(CapacityState, release_step(state, ReleaseUnderflow()), state) =
        reflexive(state)

      type RedispatchMode = RedispatchForbidden | RedispatchIdempotent
      type ResultClass = ClassCompleted | ClassRetryable | ClassPermanent | ClassDispatched
      type RetryDecision = DecideSettle | DecideRetry | DecidePermanent | DecideExhausted | DecideUnresolved

      rec RetryPolicy
        max_attempts: Int
        base_backoff_ms: Int
        max_backoff_ms: Int
        mode: RedispatchMode

      @total true
      @reducible
      fn retry_permitted(mode: RedispatchMode, class: ResultClass) -> Bool =
        match class
          ClassCompleted() -> False()
          ClassPermanent() -> False()
          ClassRetryable() -> True()
          ClassDispatched() ->
            match mode
              RedispatchForbidden() -> False()
              RedispatchIdempotent() -> True()

      fn within_limit(policy: RetryPolicy, attempt: Int) -> RetryDecision =
        pickup
          attempt < policy.max_attempts -> DecideRetry()
          else -> DecideExhausted()

      fn decide(policy: RetryPolicy, attempt: Int, class: ResultClass) -> RetryDecision =
        match class
          ClassCompleted() -> DecideSettle()
          ClassPermanent() -> DecidePermanent()
          ClassRetryable() -> within_limit(policy, attempt)
          ClassDispatched() ->
            match retry_permitted(policy.mode, class)
              False() -> DecideUnresolved()
              True() -> within_limit(policy, attempt)

      fn permanent_never_retried(mode: RedispatchMode) -> Equivalent(Bool, retry_permitted(mode, ClassPermanent()), False()) =
        reflexive(False())

      fn completed_never_retried(mode: RedispatchMode) -> Equivalent(Bool, retry_permitted(mode, ClassCompleted()), False()) =
        reflexive(False())

      fn dispatched_not_retried_when_forbidden() -> Equivalent(Bool, retry_permitted(RedispatchForbidden(), ClassDispatched()), False()) =
        reflexive(False())

`config :prometheus, global_labels: []` ran `mix deps.get && mix run
/tmp/elz107-probe.exs`, exit 0, printing `ELZ107 PROVIDER PROBE PASSED`.

Elzoo.Application. The finite probe exercised isolated counter creation,

no VM collector in the text, deregistration and collector cleanup, provider
stop/restart, loss and explicit redeclaration. This does not prove concurrency,
durability or other consumer configurations.

## Limits

- Browser contract: one domain-neutral component, bounded integers, two instances,
  attribute/event translation, keyboard activation and form isolation in Chromium.
  No production UI framework, full accessibility audit or multi-browser claim.
- BEAM exercises only the pure model; no Elixir/Cure FFI integration or browser
  runtime on BEAM. Types do not cross foreign boundaries automatically.
- Distribution is an unoptimized module directory, with licenses and a content
  receipt. Not `mix elzoo.take`, a single bundle, an npm release or a performance
  comparison. The current ready catalogue and backend dependencies are unchanged.
- No Nibble/Squirrel installation, new parser/database layer, forks or new
  agent-worker kickoff. ELZ-002 remains the next core implementation task.

## Lessons

- Nibble 1.1.4's stdlib constraint excludes this experiment's pinned 1.0.5; a
  shared language alone does not establish a compatible dependency graph.
- Upstream Gleam Erlang/OTP dependencies can print target-specific unused-value
  warnings on fresh JS builds; owned code compiles with warnings as errors.
- An upstream package may omit standalone license text (Houdini 1.2.1). Preserve
  the declared license metadata and standard license text in copied artifacts.
